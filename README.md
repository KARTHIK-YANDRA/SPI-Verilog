# SPI Communication Protocol using Verilog HDL

## Description
Implemented SPI communication protocol using Verilog HDL for synchronous serial communication.

## Features
- SPI master-slave communication
- Full Duplex communication
- Serial data transmission
- Clock synchronization
- Simulation verification

## Tools Used
- Verilog HDL
- Xilinx ISE
- Xilinx Simulator

## Project Files
- spi_master.v
- spi_slave.v
- spi_tb.v
